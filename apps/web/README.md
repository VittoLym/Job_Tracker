# Job Tracker web

Vue 3 frontend (Vite, TypeScript, Pinia, Vue Router) for the Job Tracker API.

```bash
npm ci
npm run dev          # http://localhost:5173
npm run type-check
npm run build
```

It calls `http://localhost:3000` unless `VITE_API_URL` is set. Full setup is in the [main README](../../README.md).
